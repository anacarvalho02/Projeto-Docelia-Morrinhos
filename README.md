🍬 Docelia - Catálogo Digital

Projeto de desenvolvimento de um catálogo digital para a Docelia, criado para apresentar seus produtos de forma moderna, organizada e atrativa.

O site oferece uma vitrine virtual com produtos, imagens, descrições e categorias, facilitando a navegação dos clientes e aproximando a loja do público por meio de uma experiência digital intuitiva.

Tecnologias utilizadas:
- HTML5
- CSS3
- JavaScript

Objetivos do projeto:
- Fortalecer a presença digital da loja.
- Facilitar a divulgação dos produtos.
- Proporcionar uma experiência responsiva em celulares e computadores.
- Facilitar o contato entre clientes e loja.

🚀 Projeto desenvolvido com foco em design, usabilidade e presença digital.
